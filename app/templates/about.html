About CampusConnect

A comprehensive full-stack enterprise web application engineered to modernize student life, event coordination, and campus club governance.

Core Technology Stack

Backend Architecture

Python 3.14+, Flask framework, Flask-SQLAlchemy, Werkzeug secure password hashing, WTForms CSRF token protection, and ItsDangerous cryptographic signing.

Storage & Cloud

Azure Blob Storage for scalable event banner uploads, with automatic local filesystem fallback for development.

Analytics & BI

Interactive in-app Chart.js dashboards, prepared Azure SQL views, and Power BI direct query / CSV data pipeline.

Cryptographic Attendance Verification

To prevent fraudulent or spoofed attendance check-ins, CampusConnect avoids placing raw, predictable URLs or unencrypted IDs inside QR passes:

  • HMAC-SHA256 Token Signing: Each student registration pass is generated using an encrypted, time-stamped signature containing the registration ID, event ID, and user identity.
  • Server-Side Verification: When the QR code is scanned via the organizer's camera, the payload is verified on the backend. Client-side scans are never trusted autonomously.
  • Event-Scope Enforcement: Passes scanned for Event A are immediately rejected if presented at Event B.
  • Duplicate Prevention: Once verified, attendance is locked in the relational database with unique constraints. Repeated scans within the same session trigger clear duplicate notifications with timestamp evidence.
  • Manual Fallback: In case student phone screens are broken or camera permissions are restricted, organizers can manually enter registration codes.
